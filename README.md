# كامل شوني — "حسابات المحبة" | موشن جرافيكي VOX + شعار ومض المتحرك

فيديو موشن جرافيكي عمودي (Reels 9:16 · 30fps · 2:07) على قصيدة "حسابات المحبه"، بأسلوب **VOX Mixed-Media** (كولاج ورقي، هاف تون، قصاصات ممزقة) بمزاج خليجي فخم (ذهبي/عنابي/فحمي)، ينتهي بـ**بناء شعار استوديو ومض (WAMD) بطبقات متحركة احترافية**.

## الملفات

| المسار | الوصف |
|--------|-------|
| `كاملشوني-usesuno.com.mp3` | الأغنية الأصلية |
| `motion/` | مشروع Remotion كامل (المصدر القابل لإعادة الرندر) |
| `motion/STORYBOARD.md` | الستوري بورد الكامل — 20 مشهدًا بالتوقيت |
| `motion/out/kamelshoni-motion-vox.mp4` | **الفيديو النهائي** |
| `motion/public/` | الأصول: 10 صور كولاج + الشعار + الخطوط |

## تقنيات الإنتاج

- **Remotion** (HTML/CSS/JS → MP4) — كل حركة برمجية قابلة للتعديل
- 20 مشهدًا · انتقالات متنوعة (Heart Wipe / Flash / Iris / Slide / Beat)
- كاميرا 3D (Dolly · Pan · Orbit · Crash Zoom · Pull-back) + Parallax
- تيبوغرافيا عربية حركية (Kinetic Typography) + ضربات قلم ذهبي
- خط ECG يرسم نفسه، معادلات طائرة، آلة حاسبة بقلوب، عيون، قلوب نابضة
- نبضات مزامنة على إيقاغ الأغنية (≈91 BPM) + غبار ذهبي + حبيبات ورق
- حركة 12fps (أسلوب Vox "on twos") للعناصر المرسومة
- **بناء شعار WAMD**: حلقة تدرّج ترسم نفسها → معينات وشرائط → البوابة بزنبرك → علامة W + WAMD + "ومض" → لمعة ونبضة واستقرار

## إعادة الرندر

```bash
cd motion
npm install
npx remotion render src/index.ts KamelShoni out/kamelshoni-motion-vox.mp4
```
